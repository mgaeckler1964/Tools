# Tools
Some Intenet Tools for my web site

These are the files for my galery and the blog

## ImageScript
This directory contains the php-, js- and css-files for the galery

see [Galery](https://www.gaeckler.at/Galerie/images.php) for a usage example

## ImageScript\bcp
This contains a Borland C++ Builder project that can be used to sort the images in your galery.
The program creates a .files.cfg that is read by immages.php to change the sort order.
Actually it uses an image viewer from VCL. Sometimes I will port this to winlib.

## Blog
This directory contains the php-, xsl- and css-files for the blog. Actually the php creats the menu for my own website. Sometimes I will read the menu from file simmilar to the gallery.

see [Blog](https://www.gaeckler.at/Blog/index.php) for a usage example
